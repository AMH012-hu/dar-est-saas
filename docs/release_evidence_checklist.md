# قائمة أدلة الإصدار — DAR.EST

## الغرض

تُستخدم هذه القائمة مع كل نقطة استرجاع منشورة. لا تعني علامة الاكتمال أن كل سيناريو ممكن قد اختُبر؛ بل تسجل **الدليل القابل لإعادة التحقق** الذي لزم قبل تسليم النطاق المحدد، وتوضح أي تحقق لم يُنفذ وسببه.

## بطاقة الإصدار

| الحقل | المطلوب تدوينه |
|---|---|
| رقم نقطة الاسترجاع | معرّف الإصدار الذي أعيد من الحفظ |
| نطاق التغيير | الوحدات، المسارات، والعقود المتأثرة |
| أثر البيانات | لا يوجد / ترحيل مع رقم SQL / تعديل بيانات محكوم |
| مسؤول التحقق | اسم المنفذ وتاريخ التحقق UTC |
| خطة الرجوع | نقطة الاسترجاع السابقة أو مسار التخفيف، مع حدود لا تؤثر في بيانات الإنتاج |

## قواعد القرار

لا تحفظ نقطة الاسترجاع إذا فشلت بوابة واجبة لنطاق التغيير. عند تعذر تنفيذ تحقق مصادق عليه في بيئة المعاينة، يسجل السبب بدقة ويُعوض باختبار عقد أو تحقق خادمي، ولا يوصف ذلك بأنه اختبار مستخدم حي. تُراجع التحذيرات غير الحاجبة، مثل حجم الحزمة، وتوثق كدين تقني أو بند متابعة بدلاً من تجاهلها.

> لا تستخدم هذه القائمة لإعادة قاعدة البيانات إلى حالة سابقة. الرجوع في الكود يتم بنقطة استرجاع معتمدة؛ أما بيانات الإنتاج وترحيلاتها فتتبع حدود الاسترداد الواردة في `production_quality_runbook.md`.
