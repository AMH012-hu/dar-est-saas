# تحقق لوحة المالك والاشتراكات — 20 أغسطس 2026

## نطاق الإصدار

يعيد هذا الإصدار تنظيم لوحة مالك DAR.EST حول قرار المراجعة التشغيلي: متابعة طلبات الدفع اليدوي، إثباتات التحويل، مفاتيح التفعيل، المشتركين الحاليين، وسجل التدقيق. لا يغير الإصدار مسار البيع المعتمد؛ يظل الدفع يدوياً عبر التواصل المعتمد، ولا يعني فتح رابط أو إرسال طلب تلقائياً أن الاشتراك قد فُعّل.

## ما تم التحقق منه

| المجال | الضمان المتحقق |
| --- | --- |
| الصلاحية | اعتماد أو رفض طلب الدفع اليدوي متاح للمالك أو المدير المفوض فقط، مع تسجيل قرار المراجع في سجل التدقيق. |
| إثبات الدفع | لا يظهر إجراء الاعتماد للطلب الذي لا يحتوي على إثبات مرفوع؛ يستطيع المراجع فتح إثبات الطلب قبل اتخاذ القرار. |
| حالة المراجعة | تعرض اللوحة قائمة مراجعة ذات أولوية، وحالة تحميل وفشل قابلة لإعادة المحاولة، وحداً ابتدائياً لثمانية طلبات مع خيار كشف الباقي. |
| الاشتراكات | تحتفظ اللوحة بعرض الخطة والمدة والانتهاء والحالة، وإجراءات الإلغاء أو التمديد الحالية، ومفاتيح التفعيل دون تغيير عقد الاشتراك القائم. |
| المشتركين والسجل | تضيف قائمة المشتركين بحثاً ومرشح حالة؛ ويبقى سجل التدقيق قابلاً للفرز والتصدير ضمن صلاحيات المالك. |
| الاستجابة | فُحصت لوحة المالك في شاشة سطح مكتب وعرض هاتف 390px، بما يشمل التنقل الداخلي، بطاقات المراجعة، المفاتيح، المرشحات، والسجل. |

## أدلة التنفيذ

نجح `pnpm test -- --run` بنتيجة **155 اختباراً ناجحاً** و**3 اختبارات تكامل اختيارية متخطاة**. تتحقق اختبارات الخادم من صلاحية المراجع وتدقيق قرار الاعتماد أو الرفض، فيما يحمي عقد الجاهزية مصادر واجهة لوحة المالك: التنقل الداخلي، الخطأ القابل لإعادة المحاولة، حارس إثبات الدفع، قائمة المراجعة الموسعة، مرشح المشتركين، سجل التدقيق، وحواجز التجاوب.

نجح `pnpm build`، بما في ذلك فحص TypeScript وتجميع حزمة صفحة المالك. جرت أيضاً مراجعة بصرية كاملة لمسار `/owner` على سطح المكتب والهاتف. لم تُنشأ بيانات عملاء أو دفعات تجريبية لغرض العرض؛ تعرض المراجعة فقط البيانات الموجودة في البيئة المصرح بها.

## حدود معتمدة

لا توجد بوابة دفع إلكترونية في هذا الإصدار، ولا اعتماد آلي أو تجديد آلي من حدث خارجي. يظل اعتماد طلب الدفع وقرار التفعيل قراراً يدوياً موثقاً داخل لوحة المالك، ولا تقبل عملية الاعتماد طلباً يفتقد إلى إثبات الدفع. اختبار قاعدة بيانات معزول وتشغيل تكامل Ollama Cloud ما زالا اختبارات اختيارية مقصودة، ولا يؤثر تخطيهما في حزمة الاختبارات الحتمية.
