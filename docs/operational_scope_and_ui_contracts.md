# نطاق التشغيل وعقود الواجهة المشتركة

**المالك:** فريق المنتج والهندسة في DAR.EST  
**الغرض:** تثبيت حدود ما هو متاح الآن، ومعايير واجهة موحدة قابلة للتحقق قبل أي توسعة لاحقة.

## حدود سجل إصدارات الموارد

يتتبع سجل الإصدارات غير القابل للتعديل حالياً **الوحدات وعقود الإيجار والمستندات** ضمن الشركة النشطة فقط. لكل مراجعة نوع مورد ومعرّف مورد ورقم متسلسل ومنفذ وملخص ولقطات آمنة قبل/بعد عند انطباقها. تظل روابط الوصول الموقعة وبيانات الاعتماد خارج اللقطات.

لا يوفّر الإصدار الحالي استعادة تلقائية من السجل ولا يغطي بعد أوامر العمل أو الموردين أو إعدادات الشركة. عند إضافة مورد جديد، يجب أن يكتب الإجراء التشغيلي مراجعة جديدة من خلال دفق `company_resource_revisions`، وأن يمر طلب القراءة بصلاحية `audit.read`، وألا يعدّل مراجعة سابقة.

## حدود إعدادات الشركة

تتاح إدارة الشركة حالياً من صفحة الحساب: إنشاء الشركة، عرض الأعضاء وأدوارهم، إزالة العضو غير المالك، إصدار دعوات الأعضاء أو إلغاؤها، وعرض النشاط الأخير. تبقى حالة الاشتراك وطلب الترقية في الصفحة نفسها. لا تدّعي المنصة في هذا الإصدار شاشة إعدادات موحدة لكل جوانب الشركة، ولا تشمل إعدادات علامة تجارية، أو ضرائب، أو سياسات، أو حقول مخصصة؛ لذلك تعد العضوية والدعوات والاشتراك المسارات المعتمدة الحالية. أي إضافة لاحقة لإعدادات العلامة التجارية أو الضرائب أو السياسات يجب أن تكون شركة-مقيدة، مع صلاحية كتابة واضحة وسجل نشاط وإصدار عند احتواء التعديل بيانات تشغيلية حرجة.

## عقد واجهة التشغيل

كل وجهة تشغيلية جديدة أو معدلة داخل مساحة العمل يجب أن تحقق المعايير التالية:

| المجال | العقد الملزم |
|---|---|
| الوصول | لا يجلب المسار بيانات الشركة قبل إثبات الشركة النشطة والصلاحية المطلوبة. |
| الحالات | يوفر حالة تحميل، وحالة خطأ قابلة لإعادة المحاولة، وحالة فارغة ناجحة لا تختلط بحالة الفشل. |
| الأفعال | كل إنشاء أو تعديل أو حذف يعرض حالة انتظار ويعيد جلب المصدر أو يحدّث ذاكرة الاستعلام بعد النجاح. |
| اللغة والاتجاه | النصوص الظاهرة تستخدم قاموس اللغات الحالي وتحترم اتجاه الصفحة بدل نص ثابت بلغة واحدة. |
| الجداول والنماذج | يحتفظ كل عنصر تفاعلي باسم أو تسمية قابلة للوصول، وترتبط الأفعال المدمرة بتأكيد صريح. |
| التصميم | تستخدم الواجهات رموز اللون والمسافات والأنماط الموجودة، وتحافظ على قابلية القراءة في الوضعين الداكن والفاتح وعلى الهاتف. |
| لوحة المفاتيح والحركة | يبقى مؤشر تركيز مرئي موحداً، وتحترم الحركة المخفضة إعداد نظام المستخدم؛ لا تكون الحركة شرطاً لفهم الحالة أو تنفيذ الإجراء. |

## نطاق التحقق التشغيلي

تغطي عقود المحفظة الموجودة تدرج المحفظة والمباني والوحدات، الربط مع الإيجار والتحصيل، والصلاحيات وحصص الاشتراك. وتغطي عقود مركز المبيعات بيانات العقارات والعملاء والمهام والرفع والتعديل والأدوار. تضاف اختبارات مركزة فقط عندما تثبت عقداً جديداً أو فجوة محددة؛ لا تستبدل اختبارات المصدر المعاينة البشرية لمسارات المستخدم المسجلة في قائمة أدلة الإصدار.
